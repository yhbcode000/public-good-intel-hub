# Security Policy

## Private reporting (do not open a public issue)

Use GitHub Security Advisories:

**https://github.com/yhbcode000/public-good-intel-hub/security/advisories/new**

Only maintainers can see that channel. Do **not** paste sensitive material into issues, discussions, or pull requests.

## Report privately

- Undisclosed vulnerabilities, exploit chains, 0-day details, reproducible PoCs;
- identifiable personal data: government IDs, medical records, precise home address or live location traces, private contact details;
- credentials, API keys, session tokens, database dumps or backups;
- offers to trade illegal data, or concrete methods to obtain it;
- security problems in this repository's code (`scripts/`, `.github/workflows/`).

## Public discussion is fine for

- public-good leads from already-public sources with original links;
- collaboration requests on public policy or public datasets;
- methodology, labels, agent protocol, static-page format;
- a "there may be a risk here" note that names only location and impact class; report details privately.

## If sensitive material is already public

1. Do **not** repeat, quote, or amplify details in comments.
2. Report through the advisory channel immediately with the issue/comment link.
3. Maintainers will edit or delete the sensitive body, lock the thread, record the handling, and contact GitHub Support if needed.
4. The static layer never includes such content; if it was indexed by mistake, retract it per GOVERNANCE §4.

## Expected handling

| Stage | Target (best effort, not an SLA) |
| --- | --- |
| Acknowledgement | Within 3 business days |
| High-risk public content removed | Within 24 hours |
| Fix or mitigation | Negotiated by complexity; scope and status published |

## Out of scope

- Testing third-party sites referenced by this repository: contact their owners;
- social engineering, physical intrusion, denial-of-service testing;
- reports submitted only for a bounty (this project has no bounty program).

## Research ethics

Do only the **minimum necessary** verification: do not access others' data, do not persist, and do not publish unfixed details. Violations lead to a ban and possible referral.
